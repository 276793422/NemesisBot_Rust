在看板建单，或对已有单子做 AI 拆解（planner 生成子任务并按配置自动派发）。

**用法要点**
- 建单给足上下文：标题自包含、描述带背景与边界、验收标准可客观检验——验收标准质量直接决定自动验收质量。
- 复杂任务用拆解：planner 会把父任务拆成有依赖关系的子任务并按配置派发；简单任务一张单足够，不要为拆而拆。
- 拆解纪律由 planner 保证（子单可独立验收、写同一文件的子单串行）；你的职责是把父任务的背景与验收标准写清楚。

**决策路由**
- 单步、几分钟内能完成的事 → 直接做，不必建单。
- 需要多步、多节点协作、要留进度痕迹的工作 → 建单走看板流程。
- 点对点让另一节点执行单个任务 → `cluster_rpc`；需要结构化流转与验收 → 本工具。

**约束与边界**
- 看板操作走权限与审计：建单、派发留痕可回查。
- 集群未启用时派发诚实降级（单据停在待派发），如实向用户说明状态。
