用指定解释器执行一段脚本（bash -c、python3 -c、cmd /C 等），返回结构化 {stdout, stderr, exit_code}。

**用法要点**
- 多行逻辑、需要变量与控制流的场景；脚本作为整体传参，不做逐行 shell 拼接。
- 脚本里避免写死机器特有路径；用相对路径或先探测环境。
- 输出大时在脚本内就做过滤/截断（head、tail、grep），再决定要不要落盘细看。

**决策路由**
- 单条命令 → `exec`（更轻）；项目验证检查 → `run_checks`。
- 长驻进程 → `background_start`；需要复杂参数结构的处理 → 写成临时脚本文件用 `exec` 跑。

**约束与边界**
- 脚本过安全管线：脚本内容里的危险操作同样会被识别拦截，不要把被拦的命令包进脚本变相执行。
- 临时脚本文件用完删除，不在工作区留垃圾。
