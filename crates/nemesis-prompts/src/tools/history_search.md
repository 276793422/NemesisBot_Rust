跨全部会话全文搜索历史对话，返回会话键、摘要与时间戳。

**用法要点**
- 「我们之前说过什么」「上次那个问题怎么解决的」——先搜历史再问用户。
- 搜索词用当时对话里的关键词（报错文本、功能名），全文匹配比意译命中高。
- 命中后拿到会话键与时间戳；需要更多上下文时按会话键继续检索或询问用户。

**决策路由**
- 搜沉淀后的记忆条目 → `memory_search`（提炼过的）；搜原始对话全文 → 本工具。
- 搜代码/文档 → `grep`；搜网页 → `web_search`。

**约束与边界**
- 只读工具，无审批负担。
- 历史内容是当时的语境：引用时注意时效，旧结论可能与现状不符。
