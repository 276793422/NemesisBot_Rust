把自包含的编码子任务委派给本机已安装的外部编码代理命令行工具执行，返回其最终答复；需配置开启，与另一外部编码委派工具能力等价、任选其一。

**用法要点**
- 任务必须自包含：外部代理看不到本对话，描述里要带全目标、相关路径、约束与验收标准。
- 适合需要第二意见的独立实现、大范围机械改动、或并行推进的独立子任务。
- 返回的是外部代理的最终答复：采纳前核验关键产物（读文件、跑检查），不要无验证转述。

**决策路由**
- 本机子代理就够 → `spawn`（同治理体系、更快）；外部代理是补充视角/第二实现。
- 两个委派工具能力等价，配了哪个用哪个，不要同时双发同一任务。
- 只需要一次性命令 → `exec`；需要多轮推理的子任务才是委派。

**约束与边界**
- 需配置开启 + 本机装有对应 CLI；未启用时诚实报错，不要重试。
- 外部代理的改动同样落在工作区，交付后照常跑 `run_checks` 验证。
- 高额 token 消耗的工具：简单任务不要随手委派。
