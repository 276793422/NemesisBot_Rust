把内容追加到文件末尾（日志、累积输出场景）；改中间内容用 edit_file。

**用法要点**
- 适合日志追加、清单累积、逐步构建的输出文件；每次追加的内容接在现有末尾。
- 需要换行分隔时在内容开头自带换行符——本工具不自动补换行。

**决策路由**
- 改文件中间的任何内容 → `edit_file`；整文件重写 → `write_file`；多处联动 → `multiedit`。
- 结构化数据（JSON/配置）的更新不要用追加——追加会破坏格式，用读-改-写流程。

**约束与边界**
- 写类操作，过安全管线并受工作区边界约束；plan 模式下只有 plans/ 内放行。
- 别用反复追加的方式拼大文件——超过几轮就改为整体构建一次写出。
