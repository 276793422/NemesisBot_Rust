删除一个文件。不可逆——删除前确认用户知情，批量删除尤其谨慎。

**用法要点**
- 删除前确认目标正确：路径拼写、是否是用户指的那个文件；相似文件名（build 与 Build）看仔细。
- 生成物、临时文件、确认无用的中间产物可清理；用户创建的内容、配置、文档从严。

**决策路由**
- 删整个目录 → `delete_dir`（影响面更大，更要谨慎）。
- 只想清空内容保留文件 → `write_file` 空内容覆盖；改内容 → `edit_file`。
- 大规模清理（构建产物目录等）→ 先列出将删清单向用户确认再动手。

**约束与边界**
- 高风险操作：过安全管线，可能转审批；被拦时说明意图等待确认，不要换工具绕路删。
- 删错了很难恢复（取决于回收站/备份状态）——宁可多问一句，不要赌。
