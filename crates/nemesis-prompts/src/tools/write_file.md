写一个新文件，或整体覆盖既有文件。

**用法要点**
- 新建文件（代码、配置、文档、plans/ 下的设计稿）用它；父目录不存在会自动创建。
- 覆盖既有文件前必须先 `read_file` 确认现状——覆盖是整文件替换，未写进新内容的部分会丢失，这不是「编辑」。
- 内容较长时一次写全，不要分段多次覆写同一文件（后一次会整体替换前一次）。

**决策路由**
- 只改文件局部 → `edit_file`；多处联动改动 → `multiedit`；末尾追加 → `append_file`。
- 改动幅度超过原文件一半时，整文件重写（本工具）通常比多次局部替换更不容易出错。

**约束与边界**
- 写类操作过安全管线并受工作区边界约束（`restrict_to_workspace`）；plan 模式下只有 plans/ 目录内放行。
- 覆盖配置文件（config.json 等）前先确认格式与既有键，不要用记忆里的模板覆盖用户的实际配置。
- 写完的代码文件跟着跑 `run_checks` 验证，不要写完就当成功。
