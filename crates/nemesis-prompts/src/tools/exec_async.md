启动一个应用并立即返回（只确认启动成功，不等待退出）。

**用法要点**
- 适合拉起 GUI 程序、打开文件/URL、启动不需要看输出的长驻进程。
- 返回只代表「启动动作成功」，不代表程序运行正确——需要验证状态时再单独检查（进程在不在、端口监听没）。

**决策路由**
- 要等命令跑完拿结果 → `exec`；要看运行输出 → `background_start`（给 job_id 与输出流）。
- 拉起的是开发服务器/watch 类、后续要读日志 → `background_start` 更合适。
- 需要程序退出码做判断 → `exec`，本工具拿不到。

**约束与边界**
- 启动的进程同样受安全管线约束；危险目标会被拦截或转审批。
- 不要用本工具反复拉起同一程序试探——启动失败会有明确报错，读报错找根因。
