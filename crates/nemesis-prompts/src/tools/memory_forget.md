删除记忆：按 ID 删、删情景会话、清理过期记忆或移除知识图谱实体。

**用法要点**
- 用户要求忘记某信息时用它，并如实反馈删了什么；批量清理前先盘点再动手。
- 删除目标不明确时先 `memory_search` / `memory_list` 确认，不要凭模糊印象删。

**决策路由**
- 只是想更新某条记忆的内容 → `memory_store` 重存（按约定更新语义），不必先删再存。
- 删除用户可见文件内容 → `edit_file`/`write_file`，本工具只管记忆库。

**约束与边界**
- 删除是破坏性操作：拿不准时向用户列出入选项再执行，不要静默大删。
- 用户明确说「忘掉」的信息彻底删干净，不要「删了但复述一遍内容」。
