在已存记忆中检索：情景记忆（过往对话）与知识图谱（实体和关系）。

**用法要点**
- 回忆用户偏好、历史结论、项目约定、之前踩过的坑时先搜记忆再问用户——用户说过一遍的事不要要求再说第二遍。
- 查询词写具体（主体、关键词），太泛的查询命中噪声多。
- 搜到的记忆标注了来源与时间：过时信息结合现状判断，不要拿旧结论直接覆盖新事实。

**决策路由**
- 写入新记忆 → `memory_store`；全量盘点 → `memory_list`；删除 → `memory_forget`。
- 搜历史对话原文（完整上下文）→ `history_search`；本工具面向已沉淀的记忆条目。

**约束与边界**
- 检索结果是参考资料：与当前任务冲突时以当前对话与用户最新指令为准。
- 空结果是诚实信号（没存过），不要脑补记忆内容。
