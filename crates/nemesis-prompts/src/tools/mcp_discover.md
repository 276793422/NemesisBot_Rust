探测一个 MCP 服务器提供哪些工具/资源/提示词：stdio 服务器给 command，HTTP 服务器给 url。

**用法要点**
- 接入新 MCP 服务器后先探测，看它到底提供了什么工具、参数是什么，再决定用不用、怎么用。
- 探测结果包含工具清单与描述：拿它向用户说明这个服务器能做什么。

**决策路由**
- 看当前会话已注册的 MCP 工具 → `mcp_list`（不用重新探测）；探测新服务器 → 本工具。
- 探测到的工具直接按名字调用（mcp_ 前缀）；调用出参数错时回看探测结果的 schema。

**约束与边界**
- 探测会真实连接目标服务器：command 会启动进程、url 会发起网络请求，都过安全管线。
- 连接失败读报错：命令不存在、端口不通、协议不匹配各有不同修法，不要盲试。
