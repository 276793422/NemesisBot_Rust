把需要跨会话记住的信息写入记忆（情景记忆或知识图谱实体/关系）。

**用法要点**
- 只存长期有用的事实：用户偏好、稳定约定、重要结论、项目背景；单次任务的临时状态（中间变量、当轮待办）不进记忆。
- 存之前先 `memory_search`：已有同类条目就更新或删除旧的再存，不要堆重复条目。
- 写具体：带主体、时间、条件的完整事实（「用户要求提交信息用 FIX/ADD 中文格式」），不写无法复用的泛化（「用户喜欢规范」）。

**决策路由**
- 删除记忆 → `memory_forget`；浏览全量盘点 → `memory_list`；按内容找回 → `memory_search`。
- 「写下来」与「记住」分开：要写进用户可见文件（MEMORY.md、笔记）用 `write_file`，本工具进的是检索记忆库。

**约束与边界**
- 凭据、密钥、密码不进记忆——安全管线会拦，且记忆不是秘密存储。
- 存储前想清楚这条信息未来怎么被检索到：检索键不具体，存了也找不回。
