查询本产品 CLI 命令手册：无参给总览，传命令名看详情（如 model、mcp、cluster）。

**用法要点**
- 写涉及本产品 CLI 的命令前先查，不要凭猜测拼参数——手册里有真实的子命令、旗标与默认值。
- 用户问「这个命令怎么用」时用它查权威答案，而不是靠训练记忆编造参数。

**决策路由**
- 执行命令本身 → `exec`；本工具只查手册不执行。
- 工具使用问题（不是 CLI）→ 对应工具的描述与 schema；MCP 相关 → `mcp_discover` / `mcp_list`。

**约束与边界**
- 只读工具，无审批负担。
- 手册没有的命令会诚实返回未命中——不要把没查到的命令说成「应该存在」。
