后台启动一条长时命令，立即返回 job_id（开发服务器、watch、长构建）。

**用法要点**
- 启动后用 `background_output` 增量读输出（带 next_offset 续读，只取新字节），用 `background_kill` 停止。
- 启动后先确认进入正常状态再继续别的步骤：端口开始监听、编译过首个里程碑、日志出现就绪标志——不要盲等固定秒数。
- 参数 wait_seconds 给启动确认等待窗口（1-10 秒）；需要更长确认时间就启动后轮询 `background_output`。

**决策路由**
- 会自行退出且要拿退出码的一次性命令 → `exec`。
- 启动后完全不需要输出的程序 → `exec_async`。
- 任务是「一个独立的子任务」而不是一条命令 → `spawn`（子代理能推理，后台命令只是执行）。

**约束与边界**
- 启动的进程过安全管线；危险命令会被拦截或转审批。
- 用完记得收尾：任务结束时 `background_kill` 清理，不要留一堆僵尸后台任务占资源。
- 同类服务重复启动会端口冲突——重启前先 kill 旧的。
