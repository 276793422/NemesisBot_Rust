在已配置的技能注册源里搜索可安装的技能。

**用法要点**
- 用户要「找XX技能」时先搜再报：给出候选的 registry/slug 与简介，让用户挑。
- 搜索词用英文关键词命中率高；多个结果时按简介相关性排序呈现。

**决策路由**
- 本地已装的 → `skills_list`；搜到想装的 → `install_skill`（用搜索结果里的准确 registry/slug）。
- 只想看某个已装技能的详情 → `skills_info`，不必搜。

**约束与边界**
- 只读工具，无审批负担；注册源不可达时诚实报错（网络/配置问题）。
- 安装前向用户确认要装哪个——安装动作会带入新的指令内容。
